How to run everything now
Backend (Node, in backend)
cd backend
npm install
npm run prisma:migrate
npm run prisma:generate
npm run dev (runs on 0.0.0.0:3000, accessible from other devices)
# Note: `npm run dev` now auto-runs `prisma generate` before startup


Frontend (React/Vite, in frontend)
cd frontend
npm install
Update .env file with your backend IP address:
  VITE_BACKEND_URL=http://<your-backend-ip>:3000
npm run dev (Vite dev server on 0.0.0.0:5173, accessible from other devices)


Enable HTTPS (default when PEM files are present)
1) Create/trust a local certificate (example with mkcert)
   - mkcert -install
   - mkcert localhost 127.0.0.1 ::1 <your-laptop-ip>
2) Place cert files in one of these locations (auto-detected):
   - backend/cert/localhost+1-key.pem + backend/cert/localhost+1.pem
   - backend/certs/localhost-key.pem + backend/certs/localhost.pem
   - frontend/cert/localhost+1-key.pem + frontend/cert/localhost+1.pem
   - frontend/certs/localhost-key.pem + frontend/certs/localhost.pem
   (or use env paths below)
3) Optional explicit env overrides
   Backend (backend/.env):
   - USE_HTTPS=true        # force on (or false to force off)
   - SSL_KEY_PATH=<absolute-path-to-key.pem>
   - SSL_CERT_PATH=<absolute-path-to-cert.pem>
   Frontend (frontend/.env):
   - VITE_USE_HTTPS=true   # force on (or false to force off)
   - VITE_SSL_KEY_PATH=<absolute-path-to-key.pem>
   - VITE_SSL_CERT_PATH=<absolute-path-to-cert.pem>
   - VITE_BACKEND_URL=https://<your-laptop-ip>:3000
4) Start backend + frontend again and open:
   - https://<your-laptop-ip>:5173


Access on Mobile Device
1. Find the IP address of the machine running the frontend:
   - Windows: Run `ipconfig` in terminal and look for "IPv4 Address" (usually 10.x.x.x)
   - Mac/Linux: Run `ifconfig` and look for inet address (usually 192.168.x.x)
2. On your mobile device, open: https://<frontend-machine-ip>:5173 (or http if HTTPS is forced off)
   Example: https://10.119.147.144:5173
3. The frontend will connect to the backend at the IP specified in .env file

if you're trying to restart backend but the port is already being used from before
# find out what's using port 3000
netstat -ano | findstr :3000

# Kill it (replace XXXX with the PID from above)
Stop-Process -Id XXXX -Force
